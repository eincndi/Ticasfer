UEX Corp canlı fiyat verisiyle malzeme sorgula

Nasıl çalışır?

Bu sayfa UEX Corp'un herkese açık API 2.0 servisine (uexcorp.space/api/2.0) doğrudan tarayıcından bağlanır — sunucu veya ekstra kurulum gerekmez. Malzeme fiyat sorguları için API anahtarı gerekmiyor; anahtar alanı yalnızca ileride kişisel/işlem verisi çeken uç noktalar eklenirse kullanılacak, şimdilik boş bırakabilirsin.

Not: Bu dosya senin bilgisayarında yerel olarak çalıştığı için, sorgu tarayıcının doğrudan uexcorp.space'e gönderdiği bir istektir — istek Anthropic'in sunucularından geçmez. Eğer tarayıcı bir CORS hatası verirse (bazı API'ler bunu bilinçli olarak engeller), dosyayı basit bir yerel sunucu üzerinden açman (ör. python -m http.server) sorunu çözebilir.
